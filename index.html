AI운용팀 보고서 (AI Desk Reports)

개인용 도구입니다. 개인 PC에서 돌아가는 리서치 봇들이 쓴 보고서(팀 보고서, 회의록, 성과 리포트)를 운영자 본인의 Google Drive에 Google 문서로 올려, 휴대폰에서 읽을 수 있게 합니다.

A personal, single-user tool. It copies reports written by the owner's own research bots into the owner's Google Drive as Google Docs so they can be read on a phone. It uses only the drive.file scope: it can see and change only the files it created itself.
